# Project Roadmap

## High Priority
- [ ] **Haptic Feedback:** Trigger subtle vibrations on mobile for correct/incorrect answers to reduce reliance on visual confirmation.
- [ ] **Orientation Lock:** Force landscape mode or support "Sensor Landscape" to prevent the UI from flipping when the charging cable is on the wrong side.

## Theory & Pedagogical
- [ ] **Position Naming:** Add labels for CAGED system shapes (C-shape, A-shape, etc.) when practicing in specific positional windows.
- [ ] **Interval Training:** Mode that asks for "the Perfect 5th of G on the D string" instead of just note names.

## UI/UX Polish
- [ ] **Dark Mode:** Headspace-inspired dark theme for late-night practice.
- [ ] **Custom Window Sizes:** Allow users to choose 3, 4, or 7 frets for positional drills.
