## Problem Statement
Beginner guitarists struggle with "musicality" because they don't know the notes on the fretboard. This ignorance blocks their progress with scales, chords, and theory.

## Demand Evidence
"He would not be able to practice the notes on the fretboard and wont become a better musician."

## Status Quo
Users likely use static charts or simply avoid learning the notes, leading to a slow and frustrating learning curve.

## Target User & Narrowest Wedge
**Target User:** Guitar beginner struggling with musicality.
**Narrowest Wedge:** An app that asks for a string and fret combination and requires the user to name the note.

## Constraints
- Must be simple and focused.
- Web-based for easy access and sharing.
- Vanilla JS only (to minimize "AI slop" and overhead).

## Premises
1. Beginner guitarists are the primary "desperate users" because fretboard ignorance blocks all further musical progress.
2. The core value loop is a "String/Fret -> Note" challenge that builds muscle memory.
3. Success is measured by how quickly a user can identify any note without hesitation.

## Recommended Approach: Single-Page Web App
A single `index.html` file containing all HTML, CSS, and JS. It will present a challenge (e.g., "String 6, Fret 5"), provide an input field for the answer, and give immediate visual feedback.

## The Assignment
Implement the core "String/Fret -> Note" logic and a basic UI that presents 10 challenges in a row and reports a score.
