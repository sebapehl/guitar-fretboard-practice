# Fretboard Mastery

A gamified guitar fretboard practice app built with Vanilla JS, SVG, and Supabase.

## Features
- **Identify Mode:** Name the note at the highlighted fret.
- **Locate Mode:** Find the given note on a specific string.
- **Positional Practice:** Focus on specific 5-fret neighborhoods with "Position Lock".
- **Global Leaderboard:** Compete for the fastest time with 100% accuracy.
- **Progress Tracking:** Personal bests and cloud-saved history.

## Development
